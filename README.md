# 减面工具 (su_decimate) — SketchUp 扩展

解决「模型太大、很卡」：先**扫描面数**找出重物，再**减面**降面数，尽量保持外观不变、不破面。

**Mac 版可用。** 本插件在 **SketchUp 2026 for Mac（中文界面）** 上开发并实测通过：纯 Ruby 扩展，不依赖任何系统组件、无需额外安装运行库，macOS 直接可用；Windows 版 SketchUp 同样适用。

## 功能

### 1. 面数扫描…（筛选重物）

- 列出模型里所有**组 / 组件**，按「合计面数」从多到少排列
- 列：`名称 / 类型 / 单个面数 / 实例数 / 合计面数 / 图层`
- **单击某行 = 在模型里选中它**（同名多实例会一起选中）；**双击 = 选中并缩放到该对象**
- 顶部支持「最小面数」「名称搜索」过滤；勾选「含嵌套对象」可递归列出组件/组内部的对象
- 底部「对当前选中项减面…」直接进入减面设置

实测：646MB 的别墅模型（约 1048 万面）**246 个顶层对象，扫描 8.8 秒**。

### 2. 减面…

- 对选中的组 / 组件（可多选）减面，**保留比例 5%~95%**
- 选项（默认全开）：保护轮廓 / 开口边界、传递贴图 UV、自动柔化曲面（30°）、自动补洞、递归子组子组件
- **分块执行**：有进度条、可随时取消；完成后 **一次 Cmd+Z 整体撤销**
- 完成报告：面数 前→后、减少百分比、**边界边（破面指标）前→后**、补洞数、传递 UV 的面数、耗时

## 安装

**最省事：** 下载 [最新版 su_decimate.rbz](https://github.com/biubiup0/su-decimate/releases/latest/download/su_decimate.rbz)，
SketchUp 菜单 **窗口 → 扩展程序管理器 → 安装扩展程序**，选中这个 `.rbz` 即可（仓库根目录也附了同一个文件）。
装完重启 SketchUp，菜单位置见下方。

**手工安装（macOS）：** 把 `su_decimate.rb` 和 `su_decimate/` 文件夹一起放进 SketchUp 的 Plugins 目录：

- macOS：`~/Library/Application Support/SketchUp <版本>/SketchUp/Plugins/`
- Windows：`%AppData%\SketchUp\SketchUp <版本>\SketchUp\Plugins\`

Mac 上找不到 Plugins 文件夹时：SketchUp 菜单 **扩展 → 开发者 → 打开插件目录** 可直接跳转（那是 Mac 版 SketchUp 的插件目录入口）。

也可以自己打包成 `.rbz`（zip 格式，根目录含 `su_decimate.rb` + `su_decimate/`），用 **窗口 → 扩展程序管理器 → 安装扩展程序** 安装。

安装后菜单：**扩展 → 减面工具 → 面数扫描… / 减面… / 关于·使用说明**

## 实现要点（为什么能「样式不变、不破面」）

1. **顶点聚类减面**：把顶点按空间网格合并，网格代表点取该格内顶点的平均值；**轮廓 / 开口边界的顶点被钉住**，外形轮廓不会走样。
2. **统一三角化 + `Geom::PolygonMesh` + `Entities#fill_from_mesh` 批量建面**。
   - 比逐面 `add_face` 快几百倍（实测 1 万面 0.07 秒）
   - 三角形一定是平面多边形，不会被 SketchUp 丢弃 → **这是不产生破洞的关键**
3. **贴图 UV 逐点传递**：`Face#get_UVHelper` 读取原面 UV，`Face#position_material` 写回新面，贴图位置与密度不变（只对真正有贴图的材质计算，避免拖慢）。
4. **按 30° 自动柔化**边线：曲面看起来仍然是圆滑的，硬边保持硬边。
5. 收尾**扫描边界环并补小洞**，并报告边界边数量变化供核对。
6. 面数比例用**二分搜索**求解网格尺寸：先在抽样面上搜索 12 次，再用全量面精修 2 次，实测「目标 50% → 实际 50.3%」。

## 验证结果（合成测试：9600 面的球）

| 指标 | 结果 |
|---|---|
| 目标保留 50% | 实测 4828 面（50.3%） |
| 边界边（破面指标） | 0 → 0（无破面） |
| 贴图 UV 传递 / 自动柔化 / 补洞 | 正常生效 |

## 使用建议

- 先在**中等对象**（5~20 万面）上试一次，外观满意再处理几十万面的大件
- 保留比例从 50% 起步，狠一点可以 30%
- 超大对象一轮需要几分钟，期间有进度条、随时可取消；不满意 Cmd+Z 一次回滚
- 同一组件被多处引用时，减面会**同时影响它的所有实例**（这是省内存的关键）

## 已知限制

- 顶点聚类是**近似**优化：比例越低细节损失越明显（所有减面算法的共性）
- 对超薄结构（布帘、叶片、细线）大幅减面可能出现细节丢失，建议用较温和的比例
- UI 目前只有菜单入口（可自行加工具栏按钮）
